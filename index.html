Parsing criteria
  • File types: .csv or .xlsx (first row is header). Max size 10 MB.
  • Required columns (or mapped equivalents): Date/Day, Time/Hour, Power_kW (aliases: Power, Load, Demand, kW, Power (kW)).
  • Date formats: YYYY-MM-DD, DD/MM/YYYY, or a day label (e.g., “2024-08-12” or “Day 1”).
  • Time formats: HH:mm (24h), h:mm AM/PM, or decimal hours (e.g., 14.5).
  • Power values: numeric in kW. Negatives are flagged, blanks skipped.
  • For Excel, the first sheet is read by default (you’ll be asked if multiple sheets exist).
